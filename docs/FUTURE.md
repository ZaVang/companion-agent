# Engram 后续 Sprint 规划

**更新时间**: 2026-04-13

---

## Sprint Roadmap

### Sprint 1: 核心机制补全（当前）

**目标**: 完善 Elo 竞争和动态衰减机制

**任务**:
- [ ] 实现 Elo 竞争完整逻辑
- [ ] 设计动态衰减系统
- [ ] 统一检索逻辑
- [ ] 实现 reflection 自动触发

**预计时间**: 1-2 周

---

### Sprint 2: 记忆稳定性与碎片化

**目标**: 解决碎片化记忆的稳定性问题

**任务**:
- [ ] 实现集体稳定性机制
- [ ] 设计激活阈值系统
- [ ] 优化代表神经元稳定性
- [ ] 测试记忆激活的一致性

**预计时间**: 1 周

---

### Sprint 3: DMN 模式（空闲整合）

**目标**: 实现 Default Mode Network 模拟

**任务**:
- [ ] 设计 DMN 触发条件（空闲/睡眠）
- [ ] 实现自动 reflection
- [ ] 实现 STM → LTM 固化
- [ ] 实现记忆关联发现
- [ ] 实现弱神经元清理

**预计时间**: 1-2 周

---

### Sprint 4: 因果推断层

**目标**: 从记忆网络学习因果关系

**任务**:
- [ ] 记录激活序列
- [ ] 统计共现频率
- [ ] 设计因果图数据结构
- [ ] 实现因果推断算法
- [ ] 可视化因果网络

**预计时间**: 2 周

---

### Sprint 5: 场景敏感激活

**目标**: 实现多维度场景感知

**任务**:
- [ ] 扩展场景维度（不只是 audience）
- [ ] 实现场景 → 神经元映射
- [ ] 设计场景敏感的检索权重
- [ ] 测试跨场景记忆激活

**预计时间**: 1 周

---

### Sprint 6: "共振"机制

**目标**: 实现碎片记忆的自动激活

**任务**:
- [ ] 研究神经科学的共振/同步发放
- [ ] 设计能量最小化模型
- [ ] 实现扩散激活算法
- [ ] 测试共振触发的准确性

**预计时间**: 2 周

---

### Sprint 7: 情绪与冲击力

**目标**: 实现情绪/冲击力对记忆的影响

**任务**:
- [ ] 设计情绪/冲击力评分机制
- [ ] 实现冲击力 → 衰减率映射
- [ ] 测试"差点被撞"场景
- [ ] 测试"每天遛狗"场景

**预计时间**: 1 周

---

### Sprint 8: 神经元动态增删

**目标**: 支持神经元数量的动态变化

**任务**:
- [ ] 设计神经元"死亡"机制
- [ ] 设计神经元"新生"机制
- [ ] 实现连接继承/迁移
- [ ] 测试记忆系统的鲁棒性

**预计时间**: 1 周

---

### Sprint 9: 可视化与调试工具

**目标**: 提供记忆系统可视化工具

**任务**:
- [ ] 神经元连接网络可视化
- [ ] Elo 评分变化曲线
- [ ] 衰减过程可视化
- [ ] 因果图可视化

**预计时间**: 1 周

---

### Sprint 10: 性能优化

**目标**: 优化大规模神经元的性能

**任务**:
- [ ] 索引优化
- [ ] 批量操作优化
- [ ] 内存管理
- [ ] 并行计算

**预计时间**: 1 周
