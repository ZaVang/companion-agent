## 一、碎片化记忆的稳定性问题

### 问题描述

记忆是碎片化的——一条记忆由一组神经元集合定义，但每个神经元的信号强度是变化的。

**核心矛盾**：
- 记忆定义：一组神经元的集合（静态的"成员列表"）
- 神经元状态：每个神经元的 strength/Elo 是动态变化的
- **问题**：如何在变化的神经元上稳定地"想起"记忆？

### 可能的解决方向

1. **记忆的"代表神经元"**
   - 每个 Engram 有一个 represent 神经元（代码里已有）
   - 代表神经元的稳定性 > 成员神经元的稳定性
   - 检索时先找到代表，再通过连接找到成员

2. **记忆的整体强度**
   - Engram 本身也有 strength 字段
   - 可以计算成员神经元强度的聚合值（平均值？加权平均？）
   - 记忆的"可想起程度" = Engram.strength × 成员聚合强度

3. **激活阈值机制**
   - 不是所有成员都激活才"想起"
   - 设定阈值：超过 N% 的成员强度 > T 时，记忆可被激活
   - 类似神经科学的"同步发放"概念

## 二、双向连接 vs 因果图

### 问题描述

当前设计：
```python
class NeuronCell:
    outgoing_connections: Set[Connection]  # 出连接
    incoming_connections: Set[Connection]  # 入连接
```

双向连接支持 A→B 和 B→A 同时存在。

**问题**：如果连接是双向的，构建因果图会有麻烦——因果是有方向性的。

### 神经科学背景

**实际突触连接是单向的**：
- 神经冲动从轴突（axon）传递到树突（dendrite）
- 单个突触是单向的

**但两个神经元之间可以形成双向连接**：
- A 的轴突 → B 的树突
- B 的轴突 → A 的树突
- 这是两个独立的突触，不是"一个双向突触"

**Engram 的碎片化存储**：
- 记忆分布在多个脑区
- 每个区域存储不同特征（视觉、听觉、情绪等）
- 回忆时多个区域协同激活

### 设计建议

1. **保持双向连接，但区分"信号流向"**
   - `outgoing_connections`: 我发出的信号（我能影响谁）
   - `incoming_connections`: 我接收的信号（谁能影响我）
   - 两个独立的连接集合

2. **因果图基于激活序列，而非连接存在性**
   - 连接 A↔B 表示"可能有关联"
   - 因果关系 A→B 需要验证：A 激活后，B 是否以高于随机的概率激活？
   - 因果图是"学习出来的"，不是"连接直接定义的"

3. **连接强度 ≠ 因果强度**
   - 连接强度：记忆关联的紧密程度
   - 因果强度：A 导致 B 发生的概率
   - 两者相关但不等同

## 三、记忆的"共振"机制

### 问题描述

碎片化记忆如何"自动激活"？

### 可能的实现

1. **能量最小化**
   - 神经元网络是一个能量系统
   - 外部刺激（query）注入能量
   - 网络自动收敛到能量最低点（稳定状态）
   - 收敛过程就是"想起"的过程

2. **共振频率**
   - 每个记忆有自己的"特征频率"（由神经元连接模式决定）
   - 外部刺激的频率与某个记忆匹配时，发生共振
   - 共振 = 该记忆被激活

3. **扩散激活**
   - 从 query 激活的神经元开始
   - 沿连接扩散，强度逐级衰减
   - 强度超过阈值的神经元被激活
   - 被激活的神经元集合 = 想起的记忆
