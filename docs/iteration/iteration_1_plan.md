- 需要：根据检索置信度决定是否回答

## 2. 迭代计划

### Phase 1: 修复 TR 逻辑

**目标**: 利用 Engram 的时间戳实现时间推理

**实现步骤**:
1. 检查 `NeuronCell` 是否存储 `timestamp`
2. 在 `LongMemEvalAdapter` 中实现时间推理逻辑：
   - 获取两个事件的时间戳
   - 比较时间戳判断 before/after/equal
3. 添加单元测试验证

### Phase 2: 实现 KU 能力

**目标**: 实现知识更新端点

**实现步骤**:
1. 检查 Engram 的 `MemorySystem` 是否有更新方法
2. 实现 `update_knowledge()` 方法
3. 在 `LongMemEvalAdapter` 中正确调用

### Phase 3: 优化 Abstention

**目标**: 根据检索置信度决定是否回答

**实现步骤**:
1. 分析当前置信度分布
2. 设置合理的 abstention 阈值
3. 当置信度低于阈值时返回 "Abstain"
